# EC2 F2 A7 — guía de estudio

- **Create**: POST crea con Mongoose.
- **Read**: GET consulta con find y findById.
- **Update**: PATCH usa $set para cambiar solo los campos enviados.
- **Delete**: DELETE responde 204 sin contenido.
- **new: true**: devuelve la versión nueva de la tarea.
- **runValidators: true**: fuerza reglas del esquema también durante PATCH.
- **Middleware**: valida el JSON antes del servicio.
- **AppError**: lleva el código y mensaje hasta el manejador central.

Las pruebas y reflexiones de entrega requieren que ejecutes la API y registres tus observaciones personales.
